# Tourism Website

A responsive tourism website developed using HTML, CSS, and JavaScript.

The project showcases international travel destinations through a clean and user-friendly interface, allowing users to explore different locations and navigate easily between pages.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Responsive design
- Interactive user interface
- Multiple destination pages
- Structured website navigation
- Modern layout and styling

## Project Objectives

- Practice front-end web development
- Improve website design and navigation
- Create an engaging user experience
